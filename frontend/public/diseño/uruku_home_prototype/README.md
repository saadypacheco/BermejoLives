# URUKU Home

Prototipo HTML/CSS basado en el diseño trabajado.

## Archivos
- `index.html`: estructura principal
- `styles.css`: estilos responsive
- `app.js`: punto de partida para interacción (opcional)

## Uso
Abrí `index.html` en el navegador.

## Nota
Las imágenes de ejemplo vienen de URLs públicas de Unsplash para el prototipo. Para producción conviene descargarlas/optimizarlas y servirlas desde tu propio proyecto/CDN.
